工位印钞机是一个纯本地运行的 Windows 桌面工具。它不收集你的个人数据，不需要账号，没有遥测，没有广告；你填的薪资和它记录的工时只存在你自己的电脑上。

一、我们收集哪些信息

不收集。

具体来说，本应用：

  • 不要求注册、登录或创建账号；
  • 不收集姓名、邮箱、电话号码、地址、生日等身份信息；
  • 不收集设备标识符、广告标识符、IP 地址或位置信息；
  • 不包含任何统计分析、广告、崩溃上报或用户行为追踪组件；
  • 不读取剪贴板、不记录按键内容、不截屏、不访问通讯录、照片或文件；
  • 不向任何服务器上传你的薪资、工时或使用记录。

应用会通过 Windows 提供的系统空闲接口，判断键盘鼠标是否在最近一段时间内被使用过。它只知道「有没有操作」，不知道你按了什么、输入了什么。

二、保存在你电脑上的数据

应用把数据写在 %APPDATA%\salary-visualizer 目录下，全部是本机 JSON 文件：

文件内容是否离开本机
config.json月薪、上下班与午休时间、计薪口径、五险一金比例、专项附加扣除、发薪日、窗口位置、显示设置否
activity.json每个工作日的在岗、空闲、加班时长，开始时间，离席标注与状态时间线否
game.json哪些成就提示已经展示过（纯界面状态）否
*.json.bak上述文件损坏时自动生成的备份否

这些文件不会上传、不会同步到云端，也不会被开发者读取。你可以随时用文本编辑器打开查看，或直接删除。

三、网络访问

本应用只有一个联网动作：同步公开放假安排，通常每年一次。

  • 请求只携带年份，例如 2027；
  • 不携带账号、设备标识、薪资、工时或任何可识别个人的信息；
  • 依次尝试以下公开数据源，前一个失败才换下一个：
    • https://cdn.jsdelivr.net/gh/NateScarlet/holiday-cn@master/<年份>.json
    • https://raw.githubusercontent.com/NateScarlet/holiday-cn/master/<年份>.json
    • https://www.jieri8.com/api/holidays.php?year=<年份>
  • 数据源运营方可能按其自身政策记录常规访问日志（如 IP 地址），这些日志由对方控制，本应用不附加任何标识信息。

设置中提供 「离线模式」。打开后应用完全不发起网络请求，改用内置的放假数据；代价是跨年后法定节假日可能不准，需要手动更新版本。

除上述同步外，应用不发起任何网络连接，包括自动更新、账号校验、数据回传。

你通过 Microsoft Store 安装和更新应用时，微软会按其自身隐私声明处理安装与商店相关数据。这部分不属于本应用的行为。

四、共享与第三方

  • 不向任何第三方出售、出租或共享你的数据；
  • 不接入第三方广告、统计、推送或支付 SDK；
  • 应用内没有内购，也没有付费解锁内容。

五、儿童隐私

本应用是面向职场人士的效率工具，不面向儿童设计，也不收集任何年龄信息。由于应用本身不收集任何个人数据，不存在收集儿童个人信息的情形。

六、数据安全

  • 数据只存放在你的 Windows 用户目录下，受你的系统账户权限保护；
  • 应用不把数据写到公共目录，也不开放局域网端口；
  • 应用不做云端备份。请自行通过文件备份、系统还原或整机备份保护数据；
  • 如果电脑被他人使用同一系统账户登录，对方可以看到这些文件。这不是应用能够阻止的，建议使用独立的 Windows 账户或磁盘加密。

七、保留、删除与卸载

  • 数据保留多久，完全由你决定。应用不会自动删除历史记录，也不会在后台清理；
  • 安装版（EXE）：卸载程序默认保留 %APPDATA%\salary-visualizer，方便重装后继续使用。要彻底删除，卸载后手动删除该文件夹即可；
  • 商店版（MSIX）：数据位于应用容器内，从「设置 → 应用」卸载时由 Windows 一并删除；
  • 删除该文件夹后，所有设置、记录、成就状态和 .bak 备份都会消失，且无法恢复。

八、你的权利

由于开发者不持有你的任何数据，不存在需要向开发者申请查询、更正、导出或删除的远端数据。你对本机数据拥有完全控制权：

  • 查看：用任意文本编辑器打开上述 JSON 文件；
  • 导出：应用内提供 CSV 导出（战绩 → 统计与导出）；
  • 删除：删除文件夹，或卸载应用。

如你对本政策有疑问，或认为应用的行为与上述说明不符，请通过下方邮箱联系。

九、政策变更

如果应用的功能变化导致数据处理方式改变（例如未来加入云同步），本政策会同步更新，并在文首标注新的生效日期。重大变更会在应用更新说明中提示。

在变更生效前产生的数据，仍按当时有效的政策处理。

Salary Visualizer is a local Windows desktop tool. It does not collect your personal data, requires no account, and contains no telemetry or advertising. The salary you enter and the work hours it records stay on your own computer.

1. What we collect

Nothing.

Specifically, the app:

  • does not require registration, sign-in, or an account;
  • does not collect your name, email address, phone number, address, or date of birth;
  • does not collect device identifiers, advertising IDs, IP addresses, or location;
  • contains no analytics, advertising, crash-reporting, or behavioral-tracking components;
  • does not read the clipboard, log keystrokes, take screenshots, or access your contacts, photos, or files;
  • does not upload your salary, work hours, or usage records to any server.

The app uses the Windows system idle API to determine whether the keyboard or mouse has been used recently. It knows only that input happened — never what you typed.

2. Data stored on your computer

The app writes to %APPDATA%\salary-visualizer as local JSON files:

FileContentsLeaves your PC?
config.jsonMonthly salary, work and lunch hours, pay basis, social insurance and housing fund rates, special deductions, payday, window position, display settingsNo
activity.jsonPer-workday active, idle, and overtime duration, start time, away markers, and status timelineNo
game.jsonWhich achievement notifications have been shown (UI state only)No
*.json.bakAutomatic backups created if a file is corruptedNo

These files are never uploaded, synced to the cloud, or read by the developer. You can open them in any text editor or delete them at any time.

3. Network access

The app performs exactly one network operation: syncing public holiday schedules, usually once a year.

  • The request carries only a year, for example 2027;
  • It contains no account, device identifier, salary, work hours, or any personally identifiable information;
  • It tries these public sources in order, falling back only on failure:
    • https://cdn.jsdelivr.net/gh/NateScarlet/holiday-cn@master/<year>.json
    • https://raw.githubusercontent.com/NateScarlet/holiday-cn/master/<year>.json
    • https://www.jieri8.com/api/holidays.php?year=<year>
  • The operators of those sources may keep ordinary access logs (such as IP addresses) under their own policies. Those logs are outside this app's control, and the app adds no identifying information to the request.

Settings include an Offline Mode. When enabled, the app makes no network requests and uses built-in holiday data instead; the trade-off is that public holidays may be inaccurate across a year boundary until you update the app.

Beyond this sync, the app makes no network connections — no auto-update, no account checks, no data reporting.

When you install or update the app through the Microsoft Store, Microsoft processes installation and store-related data under its own privacy statement. That processing is not part of this app's behavior.

4. Sharing and third parties

  • We do not sell, rent, or share your data with anyone;
  • The app includes no third-party advertising, analytics, push, or payment SDKs;
  • There are no in-app purchases or paid unlocks.

5. Children's privacy

This is a productivity tool for working adults. It is not directed at children and does not collect age information. Because the app collects no personal data at all, it does not collect personal information from children.

6. Security

  • Data is stored only in your Windows user profile and protected by your account permissions;
  • The app does not write to public folders or open LAN ports;
  • The app does not back data up to the cloud. Protect it with your own file, system, or full-disk backups;
  • If someone else uses your Windows account, they can read these files. The app cannot prevent that; use a separate Windows account or disk encryption.

7. Retention, deletion, and uninstalling

  • Retention is entirely up to you. The app does not automatically delete history or clean up in the background;
  • Installer version (EXE): the uninstaller keeps %APPDATA%\salary-visualizer by default so you can continue after reinstalling. To remove everything, delete that folder after uninstalling;
  • Store version (MSIX): data lives in the app container and is removed by Windows when you uninstall from Settings → Apps;
  • Once you delete the folder, all settings, records, achievement state, and .bak backups are gone permanently.

8. Your rights

Because the developer holds none of your data, there is no remote data to request, correct, export, or delete. You have full control over the data on your machine:

  • View: open the JSON files in any text editor;
  • Export: use the built-in CSV export (Records → Statistics & Export);
  • Delete: remove the folder or uninstall the app.

If you have questions about this policy or believe the app behaves differently from what is described here, contact us at the address below.

If a change in functionality alters how data is handled (for example, adding cloud sync in the future), this policy will be updated with a new effective date at the top. Material changes will be noted in the app's release notes.

Data created before a change remains governed by the policy in effect at that time.
